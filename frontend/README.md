# Frontend — Priorização Inteligente

App Next.js (App Router) com React 19, Tailwind CSS 4 e componentes shadcn/ui.

## Desenvolvimento

```bash
cd frontend
pnpm install
pnpm dev
```

Outros scripts: `pnpm build`, `pnpm lint`, `pnpm test`.

## Variáveis de ambiente

Copie `.env.example` para `.env` e configure a URL do backend (proxy em `/api/priorizacao/*`).
