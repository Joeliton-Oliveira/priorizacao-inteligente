# Agentes — frontend

## Escopo

Todo desenvolvimento deste app fica **somente** nesta pasta. Não modificar arquivos fora de `frontend/` salvo pedido explícito.

## pnpm

- Instalar e rodar sempre aqui: `cd frontend`
- Store local: `.pnpm-store` (ver `.npmrc`)
- Scripts: `pnpm dev`, `pnpm build`, `pnpm lint`, `pnpm test`
